# Corrupt Google Translate

A chaotic JavaScript snippet that visually corrupts, shakes, and glitches the Google Translate web interface. 

## How to use it

**Method 1: Browser Console**
1. Go to [Google Translate](https://translate.google.com/).
2. Press `F12` or `Ctrl+Shift+I` (`Cmd+Option+I` on Mac) to open Developer Tools.
3. Go to the **Console** tab.
4. Copy the code from `script.js`, paste it into the console, and hit **Enter**.

**Method 2: Bookmarklet**
1. Create a new bookmark in your browser.
2. Name it "Glitch Translate".
3. In the URL field, type `javascript:` and then paste the entire minified code right after it.
4. Click the bookmark while on Google Translate.
